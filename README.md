 NodeFortress v3.0

**Официальный инструмент защиты Linux-серверов и крипто-нод**

Автоматический аудит безопасности + конкретные рекомендации по устранению уязвимостей + hardening сервера. Работает на **любом** дистрибутиве Linux.

## 🚀 Установка одной командой

curl -sSL https://raw.githubusercontent.com/TeSIX/nodefortress/main/install.sh | sudo bash

📋 Как пользоваться после установки
Bash

su - checker
cd ~/checker
sudo nodefortress

🔐 Что делает NodeFortress
Инструмент выполняет глубокий аудит и выдаёт 10 категорий конкретных рекомендаций с готовыми командами:

Настройка SSH — запрет root-login, отключение паролей, fail2ban
Параметры ядра — ASLR, sysctl hardening
Firewall — ufw / nftables с правильными правилами
Политики паролей — pam_pwquality, минимальная длина, сложность
AppArmor / SELinux — принудительный режим для всех профилей
Антивирус и поиск майнеров — clamav + поиск крипто-процессов
Отключение опасных сервисов — avahi-daemon, cups и другие
Защита криптокошельков — GPG-шифрование seed-фраз (с предупреждением "НЕ ХРАНИТЕ СИДЫ В ОТКРЫТОМ ВИДЕ!")
Система обнаружения изменений — AIDE + ежедневные проверки
Мониторинг и реагирование — rkhunter, auditd, fail2ban, логирование
✨ Основные возможности
Полностью автоматическая установка
Создаёт отдельного пользователя checker (без root-прав)
Работает на Debian, Ubuntu, RHEL, Rocky Linux, AlmaLinux, Arch, openSUSE
Использует только полные пути к командам
Красивый цветной вывод
Lynis + собственные проверки
Готовые команды для исправления каждой найденной проблемы
